# AI-Powered Job Market Analytics Dashboard

## Project Overview

This Power BI project analyzes 2,253 Data Analyst job listings to uncover hiring trends, salary patterns, and the most in-demand technical skills.

## Objectives

* Analyze job opportunities by location
* Identify top hiring companies
* Explore salary trends across industries
* Discover the most demanded skills for Data Analysts

## Tools Used

* Power BI
* Power Query
* DAX
* Microsoft Excel

## Dashboard Pages

### Executive Dashboard

* Total Jobs
* Total Companies
* Average Salary
* Jobs by Location
* Top Hiring Companies

### Skills Analytics Dashboard

* SQL Demand
* Python Demand
* Excel Demand
* Power BI Demand
* Tableau Demand

### Salary Analysis Dashboard

* Average Salary by Location
* Average Salary by Industry
* Top 10 Highest Paying Companies

## Dataset

Data Analyst Jobs Dataset (2,253 job listings)

## Key Insights

* SQL and Excel were among the most requested skills.
* Python and Power BI showed strong demand.
* Salary levels varied significantly across locations and industries.
